# Video Studio 浏览器扩展

把当前页面上的视频链接一键提交给 Video Studio 分析。

## 它能做什么

- 识别当前标签页是否是受支持的视频页（B 站、YouTube、Vimeo、西瓜、腾讯、优酷、爱奇艺、抖音），或是直链媒体文件
- 一键把链接交给服务端，由 yt-dlp 下载、入库、创建分析任务
- 可填写分析目标，例如「总结核心结论，给出时间戳证据」

## 它不做什么

- **不解析播放地址**。各站点的播放地址随时会变，把解析逻辑放在扩展里等于永远追不上。扩展只负责把链接交出去。
- **不保存任何凭证**。登录态来自你在网页端建立的会话，扩展通过同源 cookie 复用。
- **不做视频预览或其他判断**。能否下载由服务端的 yt-dlp 决定，扩展只做粗筛，避免把任意网页提交过去白等一次失败。

## 安装

1. Chrome 114 或更高版本
2. 打开 `chrome://extensions`
3. 右上角开启「开发者模式」
4. 点「加载已解压的扩展程序」，选择本 `extension/` 目录

## 使用

1. 先在网页端登录 Video Studio（扩展没有登录界面，复用网页会话）
2. 打开一个视频页面
3. 点扩展图标
4. 填分析目标（可选），点「提交分析」

服务地址默认 `http://127.0.0.1:9090`，可在弹窗右上角 ⚙ 里修改。修改后会自动保存。

## 前置条件

**服务端必须安装 yt-dlp 并配置好 cookie**，否则：

- 未装 yt-dlp：接口返回「未配置 yt-dlp，无法从链接导入视频」
- 未配 cookie：B 站返回 HTTP 412（机房 IP 风控）

配置方式见 [部署说明](../docs/deployment.md)。

## 已知限制

- 提交是**同步**的：弹窗会一直显示「正在下载」，直到下载完成。10 分钟的视频约需 1-2 分钟。
- 不支持播放进度同步、时间戳跳转（这些需要注入页面脚本，且各站点播放器实现不同）。
- 短链（如 `b23.tv`）可以提交，但无法在本地还原视频 ID，因此无法做时间戳跳转。

## 测试

识别规则与服务地址规范化有单测覆盖：

```bash
cd extension
node --test detect.test.js
```
